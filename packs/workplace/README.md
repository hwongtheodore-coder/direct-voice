# Direct Voice · Workplace Pack

面向真实工作沟通的场景增强包。提供六种工作流、可复制的输入模板、完整示例和可选语气配置。与基础技能配合使用，也可以直接将模板贴入对话。

## 使用

1. 从 `templates.md` 选择场景，填写方括号内的信息。
2. 有长期偏好时，复制 `preferences.example.yaml` 并修改，在对话中附上。该文件是供模型阅读的配置，不是自动加载程序。
3. 要求模型使用 Direct Voice，并读取相应模板。核对成稿中的事实、金额、日期和承诺后使用。

## 包含内容

- 邮件精简：保留事实与承诺，删除套话。
- 客户拒绝与替代方案：守住交付边界，保持合作空间。
- 方案评审：给出判断、关键证据和可执行改进。
- 承认错误：明确影响、修正与下一次更新时间。
- 坚定协商：提出具体条件，避免空泛强硬。
- 证据型文案：把宣传主张限制在已有证据以内。
