# Direct Voice

一个让 Codex 回答更直接、更自然的技能：先回答问题，减少重复免责声明、无关提醒和过度限定，同时保留影响结论的重要不确定性。

## 使用

这是 Codex 的技能（skill），不是浏览器扩展，也不会自动改变 ChatGPT 的全局设置。将 `skills/direct-voice` 文件夹安装到 Codex 的 skills 目录后，在对话中输入 `$direct-voice`，或者要求“用直接、不防御的语气回答”。技能是否被自动选用取决于当前环境；已打开的会话可能需要重启才能发现新技能。

你也可以直接把 `SKILL.md` 中的正文作为写作偏好复制到其他支持自定义指令的 AI 产品中。

## 设计原则

- 先给结论，提供足够支撑判断的理由。
- 删除重复的免责声明和无关警告，而不是删除有用事实。
- 有实质影响的不确定性、安全限制和必要澄清仍然保留。
- 不声称能绕过平台规则或保证每次输出完全没有套话。
