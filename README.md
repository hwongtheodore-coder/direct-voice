# Direct Voice

一个让 Codex 回答更直接、更自然的技能：先回答问题，减少重复免责声明、无关提醒和过度限定，同时保留影响结论的重要不确定性。

## 使用

这是 Codex 的技能（skill），不是浏览器扩展，也不会自动改变 ChatGPT 的全局设置。将 `skills/direct-voice` 文件夹安装到 Codex 的 skills 目录后，在对话中输入 `$direct-voice`，或者要求“用直接、不防御的语气回答”。技能是否被自动选用取决于当前环境；已打开的会话可能需要重启才能发现新技能。

你也可以直接把 [`skills/direct-voice/SKILL.md`](skills/direct-voice/SKILL.md) 中的正文作为写作偏好复制到其他支持自定义指令的 AI 产品中。

## 设计原则

- 先给结论，提供足够支撑判断的理由。
- 保持独立判断：有依据时敢于提出不同意见，解释理由，也愿意根据新证据修正观点。
- 删除重复的免责声明和无关警告，而不是删除有用事实。
- 有实质影响的不确定性、安全限制和必要澄清仍然保留。
- 不声称能绕过平台规则或保证每次输出完全没有套话。

## 使用示例

输入：“把‘在样本中，这种方法可能提高准确率’改得直接些，只给成稿。”

示例成稿：“在样本中，这种方法可能提高准确率。”

这里保留了样本范围和不确定性；直接表达不要求每次都缩短原文。此处是人工编写的示例，不是模型实测输出。

## 效果与验证

现有七题对照报告中，两组总分均为 69/70，盲评偏好为技能组 4 题、基础组 1 题、平局 2 题。这次小样本测试不能证明总体质量提升，也没有验证跨模型效果；详细方法与限制见报告。

新增示例应注明是人工示例还是实际运行记录。发布新的效果结论时，应记录所测技能版本、模型、可用的运行配置、完整输入输出和评分依据，避免把预期行为写成实测结果。
